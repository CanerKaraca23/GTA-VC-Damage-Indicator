========================================================================
         DAMAGE INDICATOR FOR GRAND THEFT AUTO: VICE CITY
========================================================================

Author: Caner Karaca
Game: GTA Vice City (v1.0)
Type: ASI Plugin

DESCRIPTION
-----------
A lightweight, modern directional damage indicator for GTA Vice City.
Whenever Tommy takes damage, the screen edge illuminates with a soft 
glow indicating the attack direction and fades out smoothly.

Fully compatible with Classic Axis: rotating the camera dynamically 
updates the indicator position along the screen edges in real time.

CONFIGURATION
-------------
Configure settings in "DamageIndicator.ini":
- Enabled: Toggle mod on/off
- Color: Red, Green, Blue components (0-255)
- MaxAlpha: Peak opacity level
- Duration: Fade-out duration in milliseconds
- WidthPercent / HeightPercent: Screen edge thickness
- SmoothFade: Quadratic vs linear animation curve
- ReloadKey: Optional hotkey (e.g. 121 for F10) to reload settings live

INSTALLATION
------------
1. Ensure you have an ASI Loader installed.
2. Place "DamageIndicator.asi" and "DamageIndicator.ini" into your 
   "scripts" or game root folder.
3. Launch the game.
