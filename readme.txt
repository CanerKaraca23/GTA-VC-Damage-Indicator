         DAMAGE INDICATOR FOR GRAND THEFT AUTO: VICE CITY (v1.0)
========================================================================

Author: Caner Karaca
Game: Grand Theft Auto: Vice City (v1.0)
Type: ASI Plugin
Release Date: October 2026

------------------------------------------------------------------------
[EN] DESCRIPTION
------------------------------------------------------------------------
A lightweight, modern, and crash-safe directional damage feedback mod 
for GTA Vice City. Whenever Tommy takes damage, the corresponding screen 
edge illuminates with a smooth, soft red glow that fades out naturally.

Fully compatible with free-camera mods (such as ClassicAxisVC.asi):
the indicator tracks your active camera orientation in real time, so 
rotating the camera smoothly shifts the glow along the screen edges.

Features:
- Smooth full-edge red gradient indicating incoming attack direction.
- Dynamic 360-degree camera rotation tracking (Classic Axis compatible).
- Uniform soft vignette pulse for non-directional damage (explosions, fire).
- Zero external dependencies - pure native C++ RenderWare pipeline.
- 100% crash-safe hook that does not interfere with other ASI plugins.

------------------------------------------------------------------------
[EN] INSTALLATION
------------------------------------------------------------------------
1. Make sure you have an ASI Loader installed (e.g. Ultimate ASI Loader 
   or Silent's ASI Loader).
2. Copy "DamageIndicator.asi" into your GTA Vice City "scripts" folder 
   (or the game's root directory).
3. Start the game and enjoy!

To uninstall, simply delete "DamageIndicator.asi".

[TR] ACIKLAMA & KURULUM
------------------------------------------------------------------------
GTA Vice City icin modern, hafif ve cokme yapmayan yonlu hasar gostergesi.

3. Oyunu baslatin.

Modu kaldirmak icin "DamageIndicator.asi" dosyasini silmeniz yeterlidir.
